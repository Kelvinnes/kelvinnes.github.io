# Kelvin Kibet — Portfolio

Static portfolio site (HTML, CSS, JS). No build step.

## Add your photo
Save your photo as `assets/images/kelvin.jpg` (or `.png`, `.jpeg`, `.webp`) — portrait, ~800x880px works well. Until then a placeholder shows.

## Publish on GitHub Pages
1. Create a repo named `kelvinkibet.github.io` (or any name).
2. Push these files to the `main` branch.
3. Repo → Settings → Pages → Deploy from branch → `main` / root.
Site goes live at `https://<username>.github.io/`.

```bash
git init
git add .
git commit -m "Add portfolio"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```
